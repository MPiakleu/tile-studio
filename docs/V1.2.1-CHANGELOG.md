# Tile Studio 1.2.1 — SPFx lint and lifecycle correction

## Changes

- Removed unused `currentSiteUrl` from the TileStudioApp prop destructuring; the public prop contract remains unchanged for backward compatibility.
- Consolidated SharePoint property-pane host teardown into `unmountPaneHost` so both `ReactDom.render` roots have corresponding `unmountComponentAtNode` call paths and RushStack's pairing rule passes without disabling it.
- Added an explicit rejection handler to the asynchronous pending property-pane change flush, retaining the latest persisted configuration for retry if the deferred callback fails.
- Added regression tests for render/unmount parity, replacement-host cleanup, and deferred updates.
- Bumped package and solution version to 1.2.1 while preserving solution and web-part component IDs. All tile configuration schemas and features remain the same.
