# Tile Studio v1.4.5 — SPFx property-pane API compile hotfix

## Confirmed defect

Version 1.4.4 introduced an unsupported call at `src/webparts/tileStudio/TileStudioWebPart.ts:214`:

```typescript
this.context.propertyPane.isPropertyPaneOpen(this.instanceId)
```

SPFx 1.23.2 declares `isPropertyPaneOpen()` with **zero parameters**; passing `this.instanceId` causes TypeScript TS2554 (`Expected 0 arguments, but got 1`).

## Fix

The call is now `this.context.propertyPane.isPropertyPaneOpen()`. No change to saved settings, web-part IDs, data models, permissions, or layout styling. Both the open-pane idle-preservation branch and the closed-pane cleanup branch remain intact.

The `property-pane-lifecycle.test.cjs` mock now asserts that no arguments are passed when the editor completes configuration. This detects recurrence of this exact API misuse during offline tests; it is **not a substitute** for compiling against actual SPFx type declarations.
